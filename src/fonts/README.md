# فونت سازمانی — لحظه (Lahzeh FaNum)

فونت رسمی آکادمی. فایل‌های `.woff2` از روی `.ttf` اصلی ساخته شده‌اند
(۹۲ کیلوبایت → ۳۴ کیلوبایت به ازای هر وزن).

## وزن‌هایی که سایت بارگذاری می‌کند

`src/app/layout.tsx` این شش وزن را اعلام می‌کند:

| وزن | فایل | کجای سایت |
|---|---|---|
| ۴۰۰ | `Lahzeh-FaNum-Regular.woff2` | متن اصلی |
| ۵۰۰ | `Lahzeh-FaNum-Medium.woff2` | لینک‌های منو |
| ۶۰۰ | `Lahzeh-FaNum-SemiBold.woff2` | دکمه‌ها |
| ۷۰۰ | `Lahzeh-FaNum-Bold.woff2` | نشان‌ها و تیترهای کوچک |
| ۸۰۰ | `Lahzeh-FaNum-ExtraBold.woff2` | تیتر کارت‌ها |
| ۹۰۰ | `Lahzeh-FaNum-Black.woff2` | اعداد آمار |

## وزن‌های موجود ولی بارگذاری‌نشده

`Thin`، `ExtraLight` و `Light` در همین پوشه هستند ولی در `layout.tsx` اعلام
نشده‌اند. دلیلش این است که **Next هر فایل اعلام‌شده را preload می‌کند**؛ اعلام
وزنی که هیچ‌جای سایت استفاده نمی‌شود یعنی یک دانلود اضافه در هر بازدید.

اگر طراحی بعداً به یکی‌شان نیاز داشت، فقط یک سطر به آرایه‌ی `src` اضافه کنید.

## نکته: متادیتای وزن در فایل‌های اصلی غلط است

`usWeightClass` داخل چند فایل اشتباه ثبت شده — `SemiBold` و `ExtraBold` هر دو
۴۰۰ گزارش می‌دهند و `ExtraLight` عدد ۳۰۰. به همین دلیل وزن‌ها در `layout.tsx`
**صریح** نوشته شده‌اند و از متادیتای فایل خوانده نمی‌شوند. اگر روزی فایل‌ها را
به‌روز کردید، همین کار را ادامه بدهید.

## تبدیل دوباره از ttf

```bash
python3 -c "
from fontTools.ttLib import TTFont
import glob
for p in glob.glob('*.ttf'):
    f = TTFont(p); f.flavor = 'woff2'; f.save(p.replace('.ttf', '.woff2'))
"
```

> فونت لحظه تجاری است. فقط فایل‌هایی را اینجا نگه دارید که پروانه‌ی وب دارند.

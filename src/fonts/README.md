# فونت سازمانی — لحظه (Lahzeh FaNum)

فایل‌های فونت لحظه را در همین پوشه بگذارید. `src/app/layout.tsx` آن‌ها را از اینجا
می‌خواند و `next/font/local` خودش زیرمجموعه‌سازی، پیش‌بارگذاری و `font-display: swap`
را انجام می‌دهد.

## فایل‌های لازم

نام‌ها باید دقیقاً همین باشد (وگرنه `layout.tsx` را متناسب تغییر دهید):

| فایل | وزن | کجای سایت استفاده می‌شود |
|---|---|---|
| `Lahzeh-FaNum-Regular.woff2` | ۴۰۰ | متن اصلی، پاراگراف‌ها |
| `Lahzeh-FaNum-Medium.woff2` | ۵۰۰ | لینک‌های منو |
| `Lahzeh-FaNum-SemiBold.woff2` | ۶۰۰ | دکمه‌ها |
| `Lahzeh-FaNum-Bold.woff2` | ۷۰۰ | نشان‌ها، تیترهای کوچک |
| `Lahzeh-FaNum-ExtraBold.woff2` | ۸۰۰ | تیتر کارت‌ها |
| `Lahzeh-FaNum-Black.woff2` | ۹۰۰ | اعداد آمار، نشان‌ها |

## اگر همه‌ی وزن‌ها را ندارید

هر وزنی که فایل نداشته باشد را از `layout.tsx` حذف کنید. مرورگر وزن‌های غایب را
**مصنوعی** می‌سازد (fake bold) که در فارسی بد به‌نظر می‌رسد — بهتر است به‌جایش
نزدیک‌ترین وزن موجود را جایگزین کنید.

## فرمت

`woff2` بهترین است. اگر `ttf` یا `otf` دارید هم کار می‌کند ولی حجمش چند برابر است؛
با این دستور تبدیل کنید:

```bash
npx ttf2woff2 < Lahzeh-FaNum-Bold.ttf > Lahzeh-FaNum-Bold.woff2
```

> فونت لحظه تجاری است. فقط فایل‌هایی را اینجا بگذارید که پروانه‌ی استفاده‌ی وب
> (webfont license) دارند.

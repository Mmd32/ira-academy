# آکادمی ریتیل ایران — Iran Retail Academy

سورس‌کد وب‌سایت آکادمی ریتیل ایران. فارسی، RTL، خروجی کاملاً استاتیک.

## استک

| | |
|---|---|
| فریم‌ورک | Next.js 14 (App Router) با `output: 'export'` |
| استایل | Tailwind CSS 3.4 |
| انیمیشن | Framer Motion |
| فونت | Vazirmatn (از طریق `next/font/google`) |
| سه‌بعدی | `@google/model-viewer` (لِیزی‌لود) |
| زبان | TypeScript (strict) |

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
```

```bash
npm run build    # خروجی استاتیک در پوشه‌ی out/
```

پوشه‌ی `out/` را روی هر وب‌سروری (Caddy، Nginx، CDN) سرو کنید. به‌خاطر `trailingSlash: true`
هر صفحه یک `index.html` در مسیر خودش دارد.

`*` = در نقشه با کد رنگ «در آینده ایجاد می‌شود» علامت خورده؛ در سایت با نشان «به‌زودی»
و متن جایگزین ظاهر می‌شود. متن جایگزین را در `src/content/` با محتوای واقعی عوض کنید.

### مدل‌های برگزاری دوره

دوره‌های تخصصی به‌جای دسته‌بندی موضوعی، بر اساس **مدل برگزاری** گروه‌بندی می‌شوند
(`programModels` در [`src/content/programs.ts`](src/content/programs.ts)):

| مدل | `id` |
|---|---|
| استاندارد | `standard` |
| سازمانی — Custom-Made | `organization` |
| همکاری با انستیتوها | `institute` |
| همکاری با دانشگاه‌ها | `university` |

هر دوره یک فیلد `model` دارد. گروهی که دوره‌ای نداشته باشد، به‌جای کارت خالی پیام
«به‌زودی اعلام می‌شود» نشان می‌دهد.

### دوره‌ی شاخص (hero product)

`featuredCourse` در همان فایل، دوره‌ای است که بالای صفحه‌ی برنامه‌های آموزشی با کارت
ویژه و قفل دو لوگو (آکادمی + شریک) نمایش داده می‌شود. لوگوی هر شریک در `partners`
تعریف می‌شود. اگر `sessions` یا `hours` صفر باشد، به‌جای عدد خط تیره نشان داده می‌شود.

> ⚠️ محتوای فعلی `featuredCourse` و توضیح چهار مدل **نمونه** است و باید با متن رسمی
> جایگزین شود.

## بک‌اند

فرانت‌اند به دو اندپوینت وابسته است و هر دو در حال حاضر پیاده‌سازی نشده‌اند:

| اندپوینت | مصرف‌کننده | رفتار فعلی |
|---|---|---|
| `POST /api/lead` | `LeadForm`, `RegisterForm` | در صورت خطا، به `mailto:` بازمی‌گردد |
| `POST /api/consult` | `ConsultWidget` | در صورت خطا، پیام خطای فارسی نشان می‌دهد |

ورود درگاه دانش‌پذیران (`/portal`) فعلاً نمایشی است — با هر نام کاربری و رمز غیرخالی وارد می‌شوید.
